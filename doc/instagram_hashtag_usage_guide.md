## ⚠️ **ハッシュタグ使用時の注意点**

### **❌ 避けるべきハッシュタグ**
```
1. 関係のないトレンドハッシュタグ
   例：#猫 #ランチ #ファッション（業務と無関係）

2. 過度に競争の激しいハッシュタグのみ使用
   例：#ビジネス #仕事 #成功（埋もれやすい）

3. スパム的なハッシュタグ
   例：#フォロバ #いいね返し #相互フォロー

4. ネガティブな印象のハッシュタグ
   例：#残業 #ストレス #面倒
```

### **✅ 効果的なハッシュタグの特徴**
```
1. ターゲットが検索しそうなワード
2. 業界・サービスに直接関連
3. 地域性があり競合が少ない
4. 具体的で行動につながりやすい
5. ブランドイメージと一致
```
